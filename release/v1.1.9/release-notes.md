## 1.1.9

仅适用于已安装后端 **1.1.8** 的站点。由 52okp 统一更新中心导入并发布本 Release 的 `jc52okp-update.zip` 与 `update-manifest.json`，再由教程后端「系统更新」安装。

### 安装前必须先完成数据库迁移

本版新增会员 openid、收藏关系、历史关系的唯一索引和历史排序索引。现有在线安装器不会上传或执行迁移文件，不能直接点击安装跳过此步骤。

1. 在宝塔备份当前站点数据库，确认备份成功，选择低访问时段操作。
2. 从本 Release 更新 ZIP 中单独提取 `database/migrations/20261013120000_member_unique_keys.php`，放到服务器后端根目录的同一路径。后端根目录是包含 `think` 和 `.env` 的目录，不是 `public/`。只放入这一个迁移文件，不手动覆盖其他程序文件。
3. SSH 进入服务器后端根目录，执行：

   ```sh
   /www/server/php/84/bin/php think migrate:run --no-interaction
   ```

4. 确认迁移版本 `20261013120000` 已记录为成功。如果提示重复业务键，停止升级，先核对重复会员/收藏/历史的归属；迁移不会自动合并账号或删除记录。不要仅放文件而不执行迁移。
5. 在统一更新中心为项目 `jc52okp` 拉取 **1.1.9**，完成来源校验并发布，然后在教程后端检查更新、安装。不要修改现有 1.1.8 Release。

服务器需要 PHP GD、cURL、ZipArchive 与可用 CA 证书。若反向代理后的后台 Origin 与服务器识别值不同，在 `.env` 配置实际访问来源 `ADMIN_ORIGIN`（例如 `https://jc.52okp.com`，无路径）。建议配置 `HEALTHCHECK_URL=https://jc.52okp.com/api/home/index`，使安装后的健康检查同时验证 HTTP 业务响应。

### 本版变更

- 后台写请求增加 CSRF 和来源校验；禁用、删除、改密后撤销管理员会话，重新加载角色权限。
- 限制个人资料可写字段与文件编辑所属用户，修复文章表单内嵌 JSON 的脚本上下文问题。
- 编辑器统一为 CKEditor 5 48.5.2，原两个加载入口保留兼容桥，保留项目图片/视频上传对接。后台静态入口使用内容指纹。
- 微信登录启用 TLS 证书及主机名校验；头像验证真实图片、重编码缩放，并限制每分钟一次、每日最多十次存储尝试。
- 会员、收藏和历史写入加互斥，增加数据库唯一约束，支持同步文章的多个分类筛选。
- 历史与收藏接口支持显式分页；旧客户端保留数组结构，默认仅返回最近二十条。
- 更新健康检查核验迁移记录及实际字段；配置 HTTP 检查地址后再检查业务响应。

### 与当前线上小程序的兼容

公开文章不要求登录。无令牌、失效令牌的普通详情请求仍返回公开文章；新版小程序登录刷新失败时也能匿名阅读。旧版历史页缺少翻页入口，过渡期间仅显示最近二十条，更早记录仍在数据库中。头像上传限制即时生效。

本包仅更新后端，不包含小程序及 WordPress 插件；二者另行发布。CKEditor 许可文件与版本来源随包保留，默认 GPL 模式；商业许可可通过 `CKEDITOR_LICENSE_KEY` 配置。新版未移植旧版独立行高控件，需抽查历史文章排版和真实图片/视频上传。

### 安装后验收与回退边界

后台旧会话会失效，重新登录后验证文章保存、图片上传、状态切换和系统更新页；使用现网小程序验证首页、分类、公开详情、登录、历史及头像。

更新器备份并恢复程序文件，数据库迁移不会随代码回滚自动撤销。安装失败时先核对更新任务和数据库状态，不要覆盖 `.env`、上传目录或恢复过期数据库备份。

本地已通过小程序 23 项测试、后端 15 个测试脚本、WordPress 插件 3 个脚本及编辑器浏览器冒烟检查。生产 MySQL 5.7 并发、PHP 8.4、真实存储和微信真机尚待实际部署验收；包的完整性与基线校验不等于服务器已安装。
